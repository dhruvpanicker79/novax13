# BhoomiSetu backend dependencies.
#
# Two profiles, because the two environments are not equivalent:
#
#   WSL2 / Linux  -- everything works. This is the target.
#   Native Windows -- Smart App Control (enforced as of 2026-09-26) blocks the
#                     numeric stack entirely. Not viable; see DECISIONS.md.
#
# The engine only *requires* numpy/scipy/shapely. Everything below that line is
# either a cross-check or a convenience, and the code degrades gracefully if it
# is missing -- that is deliberate, and it is why the project survived SAC.

# --- core (hard requirements) ---
numpy>=2.0
scipy>=1.12          # needs scipy.optimize.isotonic_regression
shapely>=2.0         # needs STRtree.query returning indices

# --- model ---
xgboost>=2.0

# --- data handling ---
pandas>=2.0
requests>=2.31

# --- API ---
fastapi>=0.115
uvicorn[standard]>=0.32
pydantic>=2.9

# --- available on Linux, blocked by SAC on Windows ---
# These are NOT required. pyproj in particular is used only to cross-validate
# our from-scratch CRS engine (bhoomisetu/crs.py) -- if it agrees to
# sub-millimetre, the hand-rolled implementation is proven, which is a better
# story than having imported it in the first place.
pyproj>=3.6
rasterio>=1.3
scikit-learn>=1.5    # cross-check only; our metrics are hand-implemented

# --- dev ---
pytest>=8.0
