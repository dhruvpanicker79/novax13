Every parcel carries a calibrated confidence —
so the system can say where to send the
next surveyor, and prove it was right.

Technologies to be used:

  • Frontend: React 18 + TypeScript, MapLibre GL JS, Vite
  • Backend: Python 3.12, FastAPI + Uvicorn, OGC API – Features
  • Geometry: Shapely 2, NumPy, SciPy, GDAL/PROJ, rasterio
  • CRS: UTM 44N / WGS 84 + Everest 1830 Helmert, written from Snyder (USGS PP 1395), cross-validated against PROJ
  • Matching ML: XGBoost over 29 pairwise features; isotonic calibration; Hungarian assignment
  • Targeting: Gaussian-process error field, greedy submodular selection with the (1 − 1/e) bound
  • Data: Microsoft GlobalML Footprints, OpenStreetMap, Copernicus GLO-30, SoI CORS spec
  • Security: SHA-256 hash-chained audit, RBAC, DPDP-2023 field redaction server-side
  • Export: GeoJSON, Shapefile, CSV, signed PDF audit report
